# Changelog Studio

Changelog Studio presents a release form while VS Code remains the Markdown editor. No service or account is needed.

Choose a documentation path:

- **Learn:** [Your first release](tutorials/first-release.md).
- **Do a task:** [Use Git and existing changelogs](how-to/git.md), [develop](how-to/develop.md), or [release](how-to/release.md).
- **Look up details:** [commands](reference/commands.md), [Markdown validation](reference/markdown.md), or [CI requirements](reference/ci.md).
- **Understand the design:** [synchronization](explanation/synchronization.md) and [architecture](explanation/architecture.md).
